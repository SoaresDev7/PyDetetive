# Fase 1: Primeiros Passos

## Missão 1: Print
Use print() para exibir mensagens:
```python
print("Bem-vindo!")
```

## Missão 2: Variáveis
Guarde dados em variáveis:
```python
nome = "João"
print(nome)
```

## Missão 3: Input
Leia dados do usuário:
```python
nome = input("Qual seu nome? ")
print(nome)
```

## Missão 4: Tipos
Trabalhe com str, int, bool:
```python
idade = 16
print(idade)
```
