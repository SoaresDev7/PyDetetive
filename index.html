Bem-vindo ao PyDetetive! 🔍

                    
Olá aluno! Bem-vindo a uma aventura incrível no mundo da programação Python.

                    
O que é PyDetetive?

                    
PyDetetive é um jogo educacional onde você aprenderá Python resolvendo mistérios e completando missões de programação. Você será ajudado por vários personagens que o guiarão através de diferentes fases.

                    
Como Funciona?

                    
O jogo tem 3 fases, cada uma com 4 missões. Conforme você avança, as missões ficam mais desafiadoras. Complete as missões para ganhar créditos e desvendar o mistério!

                


                
                

                    
Como Usar PyDetetive

                    
Passo 1: Selecione uma Fase

                    
Na barra lateral, clique em uma das fases disponíveis (Fase 1, 2 ou 3).

                    
Passo 2: Escolha uma Missão

                    
Selecione uma missão da lista de missões. Você verá a descrição, código template e saída esperada.

                    
Passo 3: Escreva o Código

                    
No editor Python, escreva seu código. Você pode usar o código template como base.

                    
Passo 4: Execute e Veja o Resultado

                    
Clique em "▶ Executar Código" para rodar seu código e ver se está correto.

                    
Passo 5: Ganhe Créditos!

                    
Se seu código estiver correto, você ganhará créditos e completará a missão.

                


                
                

                    
Python Básico

                    
Print - Exibindo Texto

                    
print("Olá, Mundo!")

                    
Variáveis

                    
nome = "Alice"
idade = 15
print(nome)

                    
Operações Matemáticas

                    
soma = 5 + 3
resultado = 10 * 2
divisao = 20 / 4

                    
Condições (if/else)

                    
idade = 18
if idade >= 18:
    print("Você é maior de idade")
else:
    print("Você é menor de idade")

                    
Loops (for)

                    
for i in range(5):
    print(i)

                


                
                

                    
Dicas e Truques

                    
💡 Use Variáveis Descritivas

                    
Use nomes que deixem claro o que a variável armazena: nome_aluno em vez de x.

                    
💡 Indentação é Importante

                    
Python é sensível à indentação. Sempre use 4 espaços para indentar código dentro de blocos.

                    
💡 Peça Dicas

                    
Se estiver preso, clique em "💡 Pedir Dica" para receber orientação.

                    
💡 Teste Incrementalmente

                    
Não escreva todo o código de uma vez. Teste pequenas partes conforme avança.

                    
💡 Leia as Mensagens de Erro

                    
As mensagens de erro costumam dizer exatamente o que deu errado. Leia-as com atenção!

                


                
                

                    
Perguntas Frequentes

                    
P: O que acontece se eu escrever código errado?

                    
R: Você receberá uma mensagem de erro explicando o que deu errado. Corrija e tente novamente!

                    
P: Posso resetar uma missão e tentar novamente?

                    
R: Sim! Você pode tentar uma missão quantas vezes quiser até acertar.

                    
P: Como desbloquear as próximas fases?

                    
R: Você precisa completar todas as missões da fase atual para desbloquear a próxima.

                    
P: Os créditos servem para algo?

                    
R: Os créditos mostram seu progresso e pontuação no jogo. Quanto mais você completar, mais créditos ganhará!

                    
P: Posso pedir ajuda?

                    
R: Sim! Use o botão "💡 Pedir Dica" para receber dicas progressivas sobre a missão.
